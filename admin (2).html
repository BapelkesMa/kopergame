Membuat kunci akses GitHub (cukup sekali)

  1. Masuk ke GitHub dengan akun BapelkesMa, klik foto profil di kanan atas, lalu Settings.
  2. Di menu kiri paling bawah, klik Developer settings, lalu Personal access tokens, lalu Fine-grained tokens.
  3. Klik Generate new token. Isi nama (misal: Admin Koper Games) dan masa berlaku (misal: 1 tahun).
  4. Pada Repository access, pilih Only select repositories lalu pilih kopergame.
  5. Pada Permissions, buka Repository permissions, cari Contents, ubah menjadi Read and write.
  6. Klik Generate token, salin kode yang muncul (diawali github_pat_), lalu tempel di tombol Sambungkan ke GitHub di atas.

Jangan bagikan token ke orang di luar tim admin. Token hanya bisa mengubah isi repository kopergame. Kalau perangkat dipakai bersama, klik “Hapus token dari perangkat ini” setelah selesai.

Sambungkan ke GitHub

Setelah tersambung, setiap kali Anda menekan Simpan & terbitkan, perubahan langsung dikirim ke GitHub dan website ikut diperbarui dalam 1–2 menit. Kunci akses hanya tersimpan di browser perangkat ini.
